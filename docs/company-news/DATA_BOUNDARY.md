# Licensed computation and the AI boundary

The [WRDS AI policy](https://wrds-www.wharton.upenn.edu/pages/about/ai-policy-on-chatgpt-and-other-generative-ai-tools/) prohibits loading retrieved data into generative AI tools and lists limited vendor exceptions for protected services. RavenPack is not listed among those exceptions. An academic login, a private repository or an enterprise AI product alone is not a vendor-specific permission.

Independent code may be developed and tested with invented fixtures. Licensed calculations remain inside the authorized WRDS environment. Browser control should expose software status and code checks, not retrieved news, security records, fitted values, charts or numerical research findings to an LLM. The researcher reviews protected outputs directly under the applicable agreement. Raw records, per-security outputs, trained artifacts and aggregate dissemination each require their own review.

The public repository therefore contains independent methods and invented engineering tests. The company-news report remains marked incomplete until the real workflow and all acceptance checks have finished. Neither successful source access nor successful synthetic tests establishes empirical predictive value or publication rights. The separate public Federal Reserve study uses its documented official-source reuse terms and is unchanged.

The [WRDS download policy](https://wrds-www.wharton.upenn.edu/pages/about/data-download-and-analysis-policy/) also requires secure private storage and compliance with the actual vendor/institution agreement. No vendor data is bundled with this extension. Public release review uses an explicit file allowlist; a `.gitignore` entry alone is not a rights review.
