# Licensed computation and the AI boundary

The [WRDS AI policy](https://wrds-www.wharton.upenn.edu/pages/about/ai-policy-on-chatgpt-and-other-generative-ai-tools/) prohibits loading retrieved data into generative AI tools and lists limited vendor exceptions for protected services. RavenPack is not listed among those exceptions. An academic login, a private repository or an enterprise AI product alone is not a vendor-specific permission.

Independent code is developed and tested with invented fixtures. Licensed table processing remains inside authorized WRDS Cloud. Retrieved commercial news, vendor observations, credentials, security records, saved forecasts and trained artifacts are excluded from the public release. At the researcher’s explicit request, the researcher-authored aggregate experiment comparison is reviewed and reported separately. This is not a general exception for retrieved vendor data or a grant of data rights.

The public repository contains independent methods, invented engineering tests and the bounded [aggregate strategy comparison](STRATEGY_COMPARISON.md), including negative outcomes and ordering reversals. The original observed-only references remain unestimable, and conditional accounting does not establish actual settlement or tradable alpha. Source access and synthetic tests alone cannot establish predictive value. The separate public Federal Reserve study retains its documented official-source reuse terms.

The [WRDS download policy](https://wrds-www.wharton.upenn.edu/pages/about/data-download-and-analysis-policy/) also requires secure private storage and compliance with the actual vendor/institution agreement. No vendor data is bundled with this extension. Public release review uses an explicit file allowlist; a `.gitignore` entry alone is not a rights review.
